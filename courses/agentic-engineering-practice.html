The working product

A local support operator submits a synthetic transfer case, reads policy evidence, reviews an escalation proposal, and approves or rejects it. Later, the same assistant processes a finite queue with durable state and synthetic effects.

Keep the coding agent's project instructions separate from the runtime agent's inputs and authority. The application owns authorization and approval.

Who this is for

Experienced TypeScript engineers comfortable with async code, HTTP, Git, and a terminal. Use Node.js 22.13 or newer and one coding-agent environment. The required product interface is a terminal; local retrieval and SQLite keep the setup small.

Framework comparison, hosted observability, vector databases, and public hosting are optional. The existing main course remains a separate path.

44 hours over four weeks

Expect 10-12 hours per week. Each weekday has one 90-minute lesson; each weekend has a two-hour integration studio. Reserve 15 minutes for explanation, 55 for building and investigation, and 20 for review. Resolve a failed prerequisite before moving on.

Completion review

Demonstrate the behavior

  • A real-model run investigates a synthetic case using policy evidence and narrow tools.
  • Explain the context, model proposal, authorization, and human decision from a preserved record.
  • Show denied access and rejected approval with no escalation effect.
  • Duplicate intake and a process restart preserve one logical synthetic escalation.
  • Explain one genuine model failure from its run record. Label injected failures separately.
  • Compare a named improvement on the same cases and document acceptance or rejection.
  • Run the product and its operating instructions from a fresh session.
