One mission, two builds

Separate understanding from production trust.

Learning build · isolated

TUN + UDP tunnel in Go

You will handle packet I/O, framing, loss, authenticated encryption, nonces, replay windows, routing, MTU, shutdown, and tests. It runs only inside Linux VMs or network namespaces.

Production build · real home access

WireGuard gateway in a Proxmox VM

You will use a reviewed implementation, expose one UDP port, apply least-route and firewall policy, reach selected home services, rotate peers, monitor health, and rehearse recovery.

Security boundary

The learning tunnel is not a replacement for WireGuard. Correct cryptographic primitives do not automatically create a secure protocol: identity binding, key exchange, replay handling, state transitions, denial-of-service behavior, side channels, implementation bugs, and operations all matter.

Packet mental model

3–4 hours

Learn what a VPN changes—and what it does not—by tracing inner and outer packets, route selection, encryption boundaries, and the return path.

Gate: Given a destination, predict whether it enters the tunnel, name what each observer can see, and trace the reply.
