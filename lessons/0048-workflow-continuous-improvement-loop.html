Lesson 0048 - 40 minutes

Improve the workflow from evidence, not memory.

Write-ahead logs, evals, and retrospectives turn agent failures into changes you can test instead of folklore you eventually forget.

The One Idea

A workflow gets better only when failures are captured close to when they happen, grouped into patterns, and converted into measured changes.

Do not let "the agent should improve itself" replace engineering. The system improves when you decide what to change, why, and how success will be measured.

Write-Ahead Log

Record decisions, failures, surprises, and useful interventions while context is fresh.

Workflow Evals

Measure whether the whole system solves your task, not whether a model is impressive in isolation.

Retrospective

Turn logs and traces into patterns, hypotheses, and one change worth trying next.

Refactor Decision

Choose whether to tune one block or redesign the workflow graph.

WAL Entry

type WorkflowLogEntry = {
  time: string;
  task: string;
  block: string;
  observation: string;
  decision: string;
  evidence: string;
  followUp: string;
};

Improve One Thing

A retrospective should end with one measurable change: a new gate, a clearer template, a stricter tool policy, a better eval case, or a removed branch.

Too many simultaneous changes make the next result impossible to interpret.

Interactive Drill: Tune Or Redesign?

One block often returns invalid JSON, but the overall workflow shape still works.

Different blocks keep asking for the same missing requirement and then drifting.

A fix feels better, but there is no case proving the old failure stays fixed.

Research Habit

Agentified research should return a decision artifact: options, evidence, tradeoffs, recommendation, and what would change in the workflow.

Build Assignment

Run one mini-retrospective on your workflow agent:

  • Collect three recent trace or WAL observations.
  • Group them into one failure pattern.
  • Decide whether the fix is local or structural.
  • Add one eval case or quality gate.
  • Write how you will know whether the change helped.

Ask the agent to argue against your chosen fix before you implement it.
