Technical depth

A hosted trace must change a release decision

Export redacted spans using one dated OpenTelemetry GenAI schema and one hosted OTLP receiver. Port an existing agent case instead of making a showcase-only dataset. Verify the backend can locate a failed real run by run ID, explain its path and usage, and block a known approval or tool regression.

The one idea

Do not build a second evaluation universe for a vendor dashboard. Port the same task IDs, slices, path assertions, and release policy. The hosted system is an operational view and durable collaboration surface; deterministic checks remain the contract.

Identity

Stable eval case, run, model, and version IDs join local evidence to hosted traces.

Path

Trace model decisions, tool proposals, policy outcomes, approvals, retries, and termination.

Usage

Export latency and input/output token counts; keep raw prompt and tool content redacted.

Gate

A known approval/path regression must turn the release decision from pass to block.

Run the hosted gate

export OTEL_EXPORTER_OTLP_ENDPOINT="https://your-one-hosted-backend.example"
export OTEL_EXPORTER_OTLP_HEADERS="authorization=Bearer ..."
npm run starter:eval:hosted

# Required real-model evidence:
OPENAI_API_KEY="..." REAL_MODEL_EVAL=1 npm run starter:eval:hosted

The starter emits OTLP/HTTP JSON with a dated OpenTelemetry GenAI schema URL. Treat that schema as review-dated: GenAI conventions can still evolve.

Failure drill

Temporarily make the scripted or real model terminate before approval, or propose the write first. Run the hosted suite, confirm the command exits nonzero, find the trace by eval ID, explain the bad path without raw content, restore the contract, and link the failed/passing runs in the release record.

Build assignment

  1. Choose one hosted OTLP receiver and record the account/project setup plus retention policy.
  2. Verify redaction by inspecting an exported span.
  3. Port all current agent-cases.json cases and add the real deviation from lesson 0010.
  4. Preserve one failed trace, local exit code, diagnosis, fix, and passing rerun.
