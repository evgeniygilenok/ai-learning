Lesson 0045 - 40 minutes

Choose the implementation loop before you ask the agent to code.

The right strategy depends on ambiguity, risk, reversibility, test coverage, and how much coordination the task needs.

The One Idea

Implementation strategy is a control decision. A direct agent pass is fine for tiny, low-risk work. Complex work needs loops: plan, implement, verify, review, and possibly split across specialists.

The mistake is treating every task as the same shape because the interface is the same chat box.

Direct

Use for small, reversible changes with clear acceptance criteria and good tests.

Goal Loop

Use when the agent should keep iterating toward a goal but must report checkpoints.

Verification Loop

Use when correctness depends on repeated test, lint, eval, trace, or reviewer feedback.

Team Pattern

Use when planning, implementation, review, or research are separable enough to run as bounded roles.

Strategy Decision

type ImplementationStrategy = {
  mode: "direct" | "goal_loop" | "verification_loop" | "team";
  uncertainty: "low" | "medium" | "high";
  risk: "low" | "medium" | "high";
  gates: string[];
  checkpointEvery: string;
  rollbackPlan: string;
};

Slopwatch

AI-shaped code often shows up as unnecessary abstraction, generic comments, defensive plumbing without a requirement, and names that sound plausible but hide missing design.

Make slop detection part of the verification loop, not just a feeling during review.

Interactive Drill: Pick The Strategy

Rename one UI label and update one snapshot test.

Change retrieval ranking and prove citation quality did not regress.

Design, implement, and review a new tool runtime with auth, idempotency, and audit logs.

Template Rule

Use templates to carry standards into repeated work: risk section, test plan, changed files, rollout notes, slopwatch check, and final handoff checklist.

Build Assignment

Pick one feature in the portfolio agent runtime. Run a strategy comparison:

  • Write the direct implementation prompt you would use.
  • Write the verification-loop version with gates and checkpoints.
  • Name the extra cost of the loop.
  • Name the risk it reduces.
  • Decide which strategy you would actually use and why.

Ask the agent to do a slopwatch review of the chosen implementation plan before any code is written.
