# Starting point and target environment

The learner wants networking depth, secure access to a Proxmox home lab, a personal VPN server, and a portfolio project, but does not yet feel comfortable with Linux, IP routing, sockets, or cryptography. Future lessons should therefore make packet flow and operating-system state visible before introducing TUN code or cryptographic protocol machinery.

**Evidence:** The learner stated these goals and the intended Proxmox, Docker, and k3s environment on 2026-07-27.
