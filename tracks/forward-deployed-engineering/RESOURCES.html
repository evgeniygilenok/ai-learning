Forward deployed engineering resources

Primary technical sources checked on 2026-11-06. Read the named sections while doing the matching module. Pin the versions actually used in labs. Dynamic links may change after this review.

Knowledge

  • Python asyncio tasks. Module 01. Read cancellation and TaskGroup to reason about bounded concurrent work and cleanup.
  • Pydantic models. Module 01. Distinguish parsing, conversion, and output-model guarantees.
  • FastAPI concurrency. Module 01. Trace synchronous and asynchronous request behavior before choosing clients.
  • Pytest monkeypatch. Module 01. Replace dependencies deliberately and preserve cleanup.
  • PostgreSQL constraints. Modules 02 and 04. Enforce key scope, references, and row invariants.
  • PostgreSQL window functions. Module 02. Keep row identity while ranking or aggregating over partitions.
  • PostgreSQL EXPLAIN. Module 02. Interpret plans and measured execution rather than guessing about indexes.
  • HTTP semantics, RFC 9110. Module 03. Read method semantics and idempotency.
  • Stripe idempotency. Module 03 and lesson 0001. Study a concrete provider contract, including retention and mismatched inputs.
  • Stripe webhooks. Module 03. Study raw-body signatures, duplicates, ordering, and delivery/processing boundaries.
  • AWS timeouts, retries, and jitter. Modules 03 and 05. Reason about deadlines, load amplification, and side effects.
  • PostgreSQL isolation. Modules 04 to 05. Reproduce concurrency behavior with two sessions.
  • SQS at-least-once delivery. Modules 04 to 05. Concrete delivery contract for replay-safe consumers.
  • AWS transactional outbox. Modules 05 and 10. Separate local atomicity from remote delivery and effects.
  • OpenID Connect Core. Module 06. Explain identity, ID tokens, clients, and resource access.
  • OAuth security BCP, RFC 9700. Module 06. Check current flow and token-handling guidance.
  • PostgreSQL row security. Modules 06 and 09. Test application roles, owner bypass, and policy scope.
  • OWASP prompt injection. Modules 06 and 10. Identify direct and indirect instruction attacks and enforce permissions in code.
  • Docker build practices. Module 07. Build reproducible images and maintain deliberate dependency boundaries.
  • GitHub Actions OIDC. Module 07. Configure cloud trust for short-lived deployment credentials.
  • OpenTelemetry traces and context propagation. Modules 07 and 12. Connect API, worker, database, and provider activity.
  • Google SRE, implementing SLOs. Modules 07 and 12. Define user-relevant signals and reliability decisions.
  • OpenAI Structured Outputs. Module 08. Learn supported schema constraints and the limits of syntactic correctness.
  • OpenAI function calling. Modules 08 and 10. Separate model proposals, application execution, and tool results.
  • Anthropic, building effective agents. Module 08. Foundational workflow/agent distinctions. Its tooling discussion is historical; use current SDK documentation for implementation.
  • PostgreSQL text search. Module 09. Build a lexical baseline before adding retrieval components.
  • pgvector. Module 09. Compare exact and approximate retrieval and inspect filtered-query behavior.
  • MCP architecture and MCP security. Module 10. Dated documentation reached by current redirects at review time. Match the SDK and negotiated protocol at implementation time.
  • OpenAI evaluation best practices. Module 11. Use task-specific cases, human calibration, and repeated evaluation. The guide includes a hosted Evals-platform deprecation notice, so the course uses a local runner.
  • NIST proportion confidence intervals. Module 11. Interpret binomial success-rate uncertainty and Wilson intervals.
  • SciPy bootstrap. Module 11. Study paired resampling and its assumptions.
  • Prometheus histograms. Module 11. Understand latency aggregation and quantile-estimation limits.
  • Python debugger. Module 12. Use breakpoints and stack inspection for hypothesis-driven debugging.

Wisdom

Bring a concrete artifact to a working engineer or project maintainer: a failing reproduction, design decision, evaluation report, or handoff. Ask them to challenge one assumption. Contributing a small justified fix to a project you already use is a practical way to test unfamiliar-code skills. No community membership is required for this course.
